# Projeto GTA DevClub

Protótipo de uma página inspirada no universo de GTA, desenvolvido como exercício do DevClub. A interface apresenta uma personagem em destaque, opções de personagens e um botão visual para representar a criação de um avatar por selfie.

## Prévia

A página traz o título “Não é só um Jogo”, uma chamada para escolher uma lenda de Dev City e imagens dos personagens. O projeto está em desenvolvimento: os controles de seleção e o botão de câmera ainda não têm interação implementada.

## Tecnologias

- HTML
- CSS
- JavaScript
- Google Fonts (Bangers e Inter)

## Como visualizar

1. Clone o repositório:

   ```bash
   git clone https://github.com/cargnieli2016/projeto-gta-devclub.git
   ```

2. Abra a pasta do projeto.
3. Abra `index.html` no navegador.

Não é necessário instalar dependências ou executar um servidor.
